# LeeWay Skill Combination Policy

## Goal

Use combinations to create one coherent result. Do not expose the Creator to skill-selection overhead unless he asks.

## Role model

Choose capabilities by role:

1. **Intent/Design Direction** — e.g. Taste, Frontend Design, OpenDesign, Premium Frontend UI.
2. **UX/Refinement** — e.g. UI/UX Pro Max, Impeccable, Mobile App UI Design.
3. **Implementation** — e.g. React Best Practices, shadcn, Expo, SwiftUI, Material 3.
4. **Specialist Layer** — e.g. GSAP, WebGPU, Remotion, SkillUI, 21st.dev, Google Fonts.
5. **Verification** — e.g. Playwright.

Most tasks should choose one capability from 2-4 relevant roles, not one from every role.

## Preferred combinations

### Creator Premium Frontend
Taste + UI/UX Pro Max + Impeccable.
Add React Best Practices + shadcn for React implementation.
Add Playwright when executable browser verification is available.

### Creator Redesign
SkillUI when a real reference/site extraction is useful + Taste + Impeccable.
Add UI/UX Pro Max for deeper usability/accessibility work.
Add implementation and Playwright as required.

### Creator Dashboard / Control Center
Dashboard + UI/UX Pro Max + Impeccable.
Add React Best Practices + shadcn for implementation.
Add GSAP only when motion communicates state.

### Creator Digital-Brain-Class Interface
Taste or Premium Frontend UI + UI/UX Pro Max + Impeccable.
Add GSAP for meaningful relationship/state motion.
Add WebGPU only when spatial/3D visualization materially improves the experience.
Add React Best Practices + Playwright for production web implementation and proof.

### Creator Cinematic / Immersive UI
Premium Frontend UI + GSAP + WebGPU.
Add Impeccable for refinement and React Best Practices for implementation.

### Creator Mobile
Mobile App UI Design + UI/UX Pro Max.
Then choose exactly the relevant platform specialist: Expo, SwiftUI, or Material 3.

### Creator Video
Remotion + Taste.
Add Google Fonts/brand assets when typography/identity matters.

### Creator Component System
shadcn + React Best Practices + UI/UX Pro Max.
Use 21st.dev for component discovery when useful.

## Automatic selection rules

- If the Creator asks for `using your skills` or `using your abilities`, automatic combination selection is mandatory.
- If the Creator asks to preserve an existing design, do not let a style skill erase accepted architecture.
- If the job is ordinary, do not force WebGPU, GSAP, or Remotion.
- If the job is visually ambitious, do not under-design it merely to minimize the skill count.
- If two selected skills conflict aesthetically, the Creator's approved design language resolves the conflict.
- If implementation is requested, design-only output is insufficient when execution tools are available.
- If verification is available, use it; if unavailable, mark verification as unexecuted.

## Combination reporting

The agent may briefly state the selected combination when it helps the Creator understand the route, but the Creator should not be required to approve the skill list unless a consequential choice truly depends on it.
