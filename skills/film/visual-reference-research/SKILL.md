# LeeWay Film Visual Reference Research
Build reference boards by function: composition, lens/perspective, blocking, lighting, color, production design, movement, costume and VFX. Record what is being learned rather than copying protected shots/assets. Distinguish reference inspiration from continuity/canon requirements.
