# LeeWay Zero Trust Architecture
Follow resource-centric policy: authenticate subject/workload/device, authorize requested action/resource/context, enforce at policy enforcement points and continuously reevaluate. mTLS provides authenticated/encrypted channel identity when correctly configured; authorization remains separate. Static adjacency matrices are insufficient for dynamic context/policy.
