# LeeWay Cognitive System Architecture v1 — LOCKED BASELINE

## MASTER CHECKPOINT
This document locks the architecture established on 2026-09-21. It is a baseline, not a claim that every runtime gate is complete.

## Core objective
Make LeeWay accumulate governed capability so Agent Lee does not depend on any single model carrying the entire intelligence of the system.

## Authority spine
Creator/Human Authority → LeeWay Standards → Root of Trust → Continuity Authority → Canonical Formula → LFEA / Formula Factory / Formula Fabric → Agent Skills / Skill Houses → Context Engineering → Mechanical Imagination → Cognitive Load Transfer → Model Capability Envelope → Task Graph / Workers → Perception Harness → Tools/Providers → Real Execution → Predict/Observe → Veritas → Receipt → Learning Ledger → Capability Graduation.

## Permanent architecture laws
- A new chat is a new window, not a new identity.
- Model output is not proof.
- Generated != executed; executed != verified; available != authorized.
- PASS and FAIL both teach.
- A solved problem should reduce reasoning required for the same problem class next time.
- Stable repeated reasoning should graduate into deterministic capability.
- Before escalating model size: ground, externalize, retrieve, decompose, specialize, parallelize, simulate and verify.
- Candidate Formula never silently becomes canonical Formula.
- Providers execute capability; they do not become LeeWay authority.

## Skill Houses
Locked promoted Houses: Writing & Publishing; 3D Production; Film & Cinematic Production; Enterprise Operations; Executive Governance; Commerce & Custody; Digital Craft & Spatial Interface; Cyber Defense. Houses compose and never become silos.

## Formula
Formula Factory learns and qualifies candidate mathematics. Formula Fabric serves governed mathematical capability. GitHub Pages is discovery/publication only. Offline use requires sealed versioned hash-verified bundles. Promotion requires canonical comparison, authorization, verification and evidence.

## Model architecture
Agent Lee is persistent; models are replaceable cognitive engines. The research target is large-model-class task outcomes on verified task classes using smaller governed models. Parameter equivalence is not claimed.

## Learning
